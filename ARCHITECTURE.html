CRM Architecture

Next.js 16 + React 19 + Prisma + PostgreSQL

Frontend (React 19)

  • • Next.js App Router with route groups
  • • React Server Components (RSC) by default
  • • Client components for forms & state
  • • Tailwind CSS v4 for styling
  • • Lucide React for icons

Backend (Next.js API)

  • • Type-safe API routes with TypeScript
  • • Input validation & error handling
  • • GET, POST, PATCH, DELETE operations
  • • Prisma ORM for database access
  • • No Server Actions — all mutations via API

Database (PostgreSQL)

  • • Neon serverless PostgreSQL
  • • Prisma migrations for schema changes
  • • 3 core entities: Users, Customers, Interactions
  • • Cascade delete for referential integrity
  • • Connection pooling & auto-scaling
